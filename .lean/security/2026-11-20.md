## Findings
- MINOR KvmSettings.cs:40 — Sanitized() clamps values but not `SetAt` or `By`. A paired PC can send SetAt = long.MaxValue; KvmSync.cs:91 `NewestStamp(now) + 1` then overflows and local changes never win again (persisted). → clamp SetAt to now + small slack in Sanitized · Prove: Merge with SetAt=long.MaxValue then Set() must produce a stamp greater than any stored one.
- MINOR KvmSettings.cs:40 — a Sync JSON with a null Stamped member (e.g. "Shortcut":null) throws NullReferenceException on the link read thread; WsPipe.ReadLoop only swallows WebSocket/IO errors, so the session ends with a 500. Needs a paired peer. → treat null members as defaults · Prove: OnMessage with `{"Shortcut":null}` leaves settings unchanged and does not throw.
- MINOR KvmSync.cs:144 (LocalZones) — `layout.By` comes from the peer; a peer setting By to our fingerprint skips the turn-around, so its zones (arbitrary Peer string) are stored as-is. Effect limited to layout of a paired PC. → ignore By from the wire (use the link's fingerprint), force Peer = link fingerprint · Prove: peer layout with By = our fingerprint and Peer = other fingerprint is stored with Peer = sender.
